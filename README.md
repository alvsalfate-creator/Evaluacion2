# Evaluación 2 - Geolocalización con GraphHopper

Este proyecto contiene un script en Python que consume la API de GraphHopper para calcular rutas entre dos ubicaciones, mostrando la distancia en kilómetros/millas y la narrativa del viaje paso a paso en español.

## Instrucciones de ejecución
1. Asegúrate de tener Python 3 instalado en la máquina virtual DEVASC.
2. Instala la librería `requests` ejecutando en la terminal:

   pip install requests
